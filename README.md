# LeadShield

Author: Daniel Hallman

Preview contact form screening, manage rules for connected sites, review retained blocked messages, and generate setup instructions.

## Connect

1. Connect your MCP client to `https://rankandrent-leads.hallmanlab.workers.dev/mcp`.
2. Sign in to LeadShield and grant access to the intended sites.
3. Ask for a site's saved screening rules. A successful response identifies that site and returns its effective policy.

Preview rule changes before saving. After an authorized save, read the rules again to verify the saved values. Access is limited to sites connected to your account.

## Screening and reports

The ChatGPT screening tool previews a decision. It does not store or deliver a lead or process payment. Reports show retained blocked messages for the returned UTC dates. They do not establish an overall spam rate.

Setup instructions do not install a website script or workflow. After an authorized installation, test accepted and blocked synthetic submissions and check the actual delivery destination.

The website service offers free rule-based bot checks and pay-as-you-go message screening at $0.01 per submission. Review current service terms before enabling it.
