# LeadShield Contact Form & B2B Solicitation Blocker

Filter contact form spam and unwanted sales pitches on HighLevel, WordPress, HubSpot, and custom websites. Set rules for each site and review blocked submissions. Rule-based bot blocking is free; message screening costs $0.01 per submission on the pay-as-you-go plan.

## Quick start

1. Open the [LeadShield setup guide](https://ghlagencymcp.com/use-cases/ghl-contact-form-spam-blocker) and choose your website or CRM.
2. Connect a client that supports Streamable HTTP MCP to `https://rankandrent-leads.hallmanlab.workers.dev/mcp`.
3. Check the intended site's active rules with `leadshield_get_spam_policy` before making changes. See the [form screening instructions](../leadshield-form-spam-blocker/SKILL.md) for the available tools.
